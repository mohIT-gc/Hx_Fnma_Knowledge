# MyServices Developer Onboarding Guide

Start with the MyServices architecture overview and deployment flow before taking implementation work.

## First-week reading

1. Read the MyServices product overview.
2. Review the service boundaries, downstream dependencies, and error-handling expectations.
3. Read the access request process before requesting elevated roles.
4. Review support escalation guidance and production change controls.

## Development setup

- Join the MyServices engineering Slack channel.
- Confirm access to source control, CI pipelines, deployment dashboards, and observability tools.
- Pair with a team owner on the first production-impacting change.

## Operating expectations

- Production changes require change-record linkage.
- Customer-impacting incidents must be handed off through the defined on-call process.
- Sensitive servicing data must only be accessed through approved operational workflows.
