# MyServices Access Request Process

Use this process when a developer needs MyServices environment access.

## Standard access

- Request `myservices-read` for source, dashboards, and non-production observability.
- Request `myservices-deploy` only after onboarding tasks and deployment training are complete.
- Request `myservices-prod-observe` for production monitoring after manager approval.

## Approval requirements

1. Complete required security and servicing-data training.
2. Obtain manager approval in AccessHub.
3. Confirm the request maps to your team assignment and current work.

## Notes

- Production-changing permissions are not granted by default.
- Escalate stuck requests through the MyServices Platform engineering manager.
